# Inkflow · Demonstração

Acesse a demo: [pedrocventura.github.io/inkflow-demo](https://pedrocventura.github.io/inkflow-demo/).

Este repositório contém apenas as telas compiladas e recursos visuais da demonstração. Todos os dados são fictícios e gerados no navegador. Não há login, banco, cadastro real ou armazenamento das alterações. Use o seletor no topo para conhecer os perfis de tatuador, guest, estúdio e administração da plataforma.

O código-fonte completo da aplicação é mantido em um repositório privado. Não use esta demonstração para atendimento real.
